# GitHub profile handoff

This folder is prepared locally. No repository or organization setting has been changed by this brand-kit build.

To publish the organization profile, use a public repository named `phonlet-ai/.github` and put the contents of this folder inside that repository. The profile file must be `profile/README.md`. Keep `profile/assets/` beside it. The prepared image URLs assume the default branch is `main`; change those URLs when using another branch name. Review the wording before publishing. This is an org profile README, not a personal profile repository.

Use `icons/png/phonlet-ai-avatar-dark-512.png` from the main kit for the organization avatar. The SVG version is the editable source. Paste the organization copy from `organization-copy.txt` into the corresponding profile fields. Do not fill in an unconfirmed website, email address, or social account.

The proposed component names do not assert that those repositories already exist. Add links and pin repositories as they become useful to visitors; do not publish placeholder performance badges.

Official instructions, checked 2026-09-29:
https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile
