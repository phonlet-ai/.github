<h3 align="center">Speech intelligence for edge devices.</h3>

Phonlet AI is building lightweight, on-device speech tools: voice activity detection, wake-word detection, grapheme-to-phoneme conversion, phoneme models, and the audio infrastructure that connects them.

Our focus is practical components for developers building local voice interfaces.

### Component family

| Component | Focus |
| --- | --- |
| **Phonlet VAD** | Voice activity detection. |
| **Phonlet Wake** | Wake-word detection. |
| **Phonlet G2P** | Grapheme-to-phoneme conversion. |
| **Phonlet Phones** | Streaming phoneme models. |
| **Phonlet Audio** | Audio frontends and feature extraction. |
| **Phonlet Runtime** | On-device inference and integration. |

This is the intended component family. Availability, supported devices, benchmarks, and licensing are documented in each repository as it is published.
